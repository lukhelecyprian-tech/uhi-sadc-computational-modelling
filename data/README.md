# Research Input Data

This directory documents external research datasets.

The large Landsat-derived GeoTIFF files and generated
simulation input arrays are not included in this repository.

The research uses Landsat 8 Collection 2 Level-2
observations for Mbabane, Manzini and Johannesburg.

Required variables include:

- Land surface temperature
- NDVI
- Surface albedo
- Surface reflectance

The source data, processing methods, study masks and
input-file preparation procedures must be documented
before the complete computational workflow can be
considered independently reproducible.

Do not commit large raster datasets, credentials,
personal information or temporary simulation files.
